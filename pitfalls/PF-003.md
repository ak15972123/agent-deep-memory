---
id: PF-003
title: Cargo Install 触发 edition2024 版本不兼容错误
date: 2026-03-04
---

## 失败链 (Failure Chain)
1. 用户的 Rust 工具链版本为 1.75.0。
2. 在克隆了开源项目并执行 `cargo install --path crates/openfang-cli`（未带 `--locked`）时，Cargo 会自动尝试去拉取依赖库的最新符合 SemVer 范围的版本。
3. 依赖项 `wasmtime-internal-versioned-export-macros` 最新的 41.0.4 抢先应用了 `edition2024`（该版本在 1.75 中尚未被 Cargo 广泛稳定支持）。
4. 编译阻断报错：`The package requires the Cargo feature called edition2024, but that feature is not stabilized in this version of Cargo (1.75.0).`

## 根因 (Root Cause)
未执行 `cargo install` 时附带读取和强制消费项目源码内定义好的稳定版本树（即 `Cargo.lock`），导致隐式抓取了使用了未来特性 (edition2024) 的自动上游迭代版本。此坑与用户的 1.75.0 CLI 构建场景产生冲突。

## 正解 (Solution)
始终使用锁版本进行源码级别二进制包的全局安装：
`cargo install --path crates/openfang-cli --locked`

或者直接将本机的标准编译工具链拉到 2024 语法的可用稳定版基线上：
`rustup update`
